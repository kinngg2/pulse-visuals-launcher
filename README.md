# WTF

WTF is a static social-network prototype inspired by compact community feeds: profiles, short posts, trending topics, live rooms, and creator discovery.

## Run locally

Open `index.html` in a browser or serve the folder with any static server.

```powershell
npx serve .
```

## Project structure

- `index.html` — single-page social-network UI
- `styles.css` — responsive layout, dark theme, interactions
- `script.js` — mock feed rendering and composer interactions
